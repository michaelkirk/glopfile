# glopfile

Client library and CLI application for the glopfile protocol.

## ⚠️ Experimental — do not trust this

This is an experiment, published so it can be installed conveniently, not
because it is ready to be relied on. Treat it accordingly:

- It has not been audited, and it moves files around over a network while
  claiming to encrypt them. Do not use it for anything you would mind losing,
  leaking, or corrupting.
- The protocol, the APIs, and the on-disk and on-wire formats can all change
  without notice, in any release.
- Parts of it are LLM generated and have not been reviewed to the standard that
  security-relevant code deserves.
